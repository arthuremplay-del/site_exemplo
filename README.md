# Arthur Gamer Webpage

A dynamic and visually engaging web page featuring a modern, "gamer" aesthetic. It includes 3D interactive elements, a glitch text effect, an animated particle background, and a simple hidden 2D shooting game to grab attention!

## Features
- **Neon Cyberpunk Aesthetic**: High-quality visual design with a custom `style.css`.
- **Interactive 3D Card**: Parallax effect that follows the cursor.
- **Glitch Effect Text**: Eye-catching CSS animation.
- **Mini Shooting Game**: A hidden click-to-shoot game where neon targets spawn on the screen.
- **Score Tracking**: Keep track of your score in the UI box as you shoot down the targets.

## Technologies Used
- HTML5
- CSS3 (Variables, Keyframes, Flexbox, Gradients)
- Vanilla JavaScript (ES6 Modules, DOM Manipulation, Event Listeners)

## How to Play the Mini-Game
1. Open `index.html` in your favorite web browser.
2. Wait a few seconds for alien targets (👾) to spawn on the screen.
3. Use the custom crosshair cursor to aim and click on the targets to destroy them and increase your SCORE!
